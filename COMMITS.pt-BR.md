# Registro de entregas

[English](COMMITS.md)

O Git contém hashes e datas reais. Os registros descrevem marcos entregues,
sem narrativa diária fabricada. O desenvolvimento usou assistência de IA,
sem alegação de autoria sem assistência.

- `feat(clearledger): reconcile immutable settlement snapshots` — CSV estrito,
  persistência atômica/idempotente, exceções de pedidos e repasses, cobranças
  divididas, reembolsos, proveniência e 37 testes de domínio aprovados.
- `feat(clearledger): expose authenticated reconciliation API and CLI` —
  API protegida, limite de entrada, erros seguros, CLI, exportações e documentação
  bilíngue de trabalho em andamento; 64 testes locais aprovados. Teste com
  servidor real e auditoria de dependências permanecem pendentes neste marco.
